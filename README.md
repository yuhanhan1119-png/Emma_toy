# Sanrio 大亂鬥 ✨

可愛的 Sanrio 角色對戰遊戲！

## 角色

- 🍮 **布丁狗** (Pompompurin)
- ☁️ **大耳狗** (Cinnamoroll)
- 🎀 **Hello Kitty**
- 💜 **酷洛米** (Kuromi)
- 🌸 **美樂蒂** (My Melody)

## 遊戲模式

- **單人對戰**：與電腦 AI 對戰
- **雙人對戰**：兩位玩家輪流操作

## 如何遊玩

直接在瀏覽器開啟 `index.html` 即可遊玩，無需安裝。

```bash
# 或使用簡易 HTTP 伺服器
npx serve .
```

### 操作說明

**單人模式**：點擊按鈕選擇 攻擊 / 必殺技 / 治療

**雙人模式**：
- 玩家 1：`A` 攻擊 | `S` 必殺技 | `D` 治療
- 玩家 2：`J` 攻擊 | `K` 必殺技 | `L` 治療

## 單人模式戰鬥

- **普通攻擊**：低傷害（1 點），每次攻擊累積 1 格能量
- **能量系統**：連續攻擊 5 次後能量滿格
- **大招 (W)**：能量滿時按 `W` 鍵發動角色專屬大招

| 角色 | 大招 | 傷害 |
|------|------|------|
| 布丁狗 | Pudingo's Shaking Body | 10（超強！） |
| 大耳狗 | Flying Fist | 8 |
| Hello Kitty | Hello Kitty's Scream | 8 |
| 酷洛米 | Dream Tree | 8 |
| 美樂蒂 | Pee-Pee-Tree | 8 |

## 遊戲流程

1. **主選單** — 選擇單人對戰或雙人對戰
2. **角色選擇** — 挑選你的戰士
3. **攻擊選擇** — 確認角色的專屬攻擊招式
4. **回合制戰鬥** — 使用專屬攻擊、普通攻擊或治療
