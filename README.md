# Sanrio 大亂鬥 ✨

可愛的 Sanrio 角色對戰遊戲！

## 角色

- 🍮 **布丁狗** (Pompompurin)
- ☁️ **大耳狗** (Cinnamoroll)
- 🎀 **Hello Kitty**
- 💜 **酷洛米** (Kuromi)
- 🌸 **美樂蒂** (My Melody)

## 遊戲模式

- **單人對戰**：與電腦 AI 對戰
- **雙人對戰**：兩位玩家輪流操作

## 如何遊玩

直接在瀏覽器開啟 `index.html` 即可遊玩，無需安裝。

```bash
# 或使用簡易 HTTP 伺服器
npx serve .
```

### 操作說明

**單人模式**：點擊按鈕選擇 攻擊 / 必殺技 / 治療

**雙人模式**：
- 玩家 1：`A` 攻擊 | `S` 必殺技 | `D` 治療
- 玩家 2：`J` 攻擊 | `K` 必殺技 | `L` 治療

## 動作對戰模式

- **起始生命**：每位角色 **500** 點生命
- **生命減少**：戰鬥中生命會慢慢下降，被攻擊也會扣血
- **勝利條件**：生命歸零時遊戲結束，**生命最高者獲勝**

### 操作方式

| 模式 | 移動 | 跳躍（閃避攻擊） |
|------|------|------------------|
| 單人 | ↑↓←→ 方向鍵 | Space 或跳躍按鈕 |
| 雙人 | 玩家1：方向鍵 / 玩家2：WASD | 玩家1：Space / 玩家2：Shift |

跳躍可以閃避對手的攻擊彈！
