# 萌萌可愛大亂鬥 ✨

可愛角色對戰遊戲！

## 角色

- 🍮 **布丁狗** (Pompompurin)
- ☁️ **大耳狗** (Cinnamoroll)
- 🎀 **Hello Kitty**
- 💜 **酷洛米** (Kuromi)
- 🌸 **美樂蒂** (My Melody)

## 遊戲模式

- **單人對戰**：與電腦 AI 對戰
- **雙人對戰**：兩位玩家輪流操作

## 如何遊玩

直接在瀏覽器開啟 `index.html` 即可遊玩，或執行：

```bash
npx serve .
```

然後開啟 http://localhost:3000

## 遊戲流程

1. 主選單 → 選擇單人或雙人
2. 選擇角色 → 開始戰鬥
3. 動作對戰場地即時戰鬥

## 動作對戰模式

- **起始生命**：每位角色 **500** 點生命
- **生命減少**：戰鬥中生命會慢慢下降，被攻擊也會扣血
- **勝利條件**：生命歸零時遊戲結束，**生命最高者獲勝**

### 操作方式

| 模式 | 移動 | 跳躍（閃避攻擊） |
|------|------|------------------|
| 單人 | ↑↓←→ 方向鍵 | **D** 攻擊累能量 / **W** 大絕(需5次) | Space 或跳躍按鈕 |
| 雙人 | 玩家1：方向鍵 / 玩家2：WASD | 玩家1：D/J 攻擊 K大絕 / 玩家2：J/K | 玩家1：Space / 玩家2：Shift |

跳躍可以閃避對手的攻擊彈！

**大絕規則**：連續按 D 攻擊 5 次累滿能量，才能按 W 發動一次大絕。
