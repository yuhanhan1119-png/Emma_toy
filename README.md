# Emma_toy · 可愛遊戲樂園 (Kawaii Game Land)

一個三麗鷗風格的小遊戲合集，進入後可從選單挑選遊戲：

## 🔍 尋找可愛夥伴 (Kawaii Seek)

一款「尋找威力」風格的找找看遊戲：在滿滿的可愛角色中，找出指定的夥伴！

- 🎀 共 **15 關**，每關限時 **3 分鐘**
- 👀 依提示點擊畫面中的目標角色，找齊即可過關
- ⏱️ 越後面的關卡角色越多、越小、目標越多，難度逐漸提升
- ⭐ 剩餘時間越多，過關獎勵分數越高；點錯會扣時間

## 🏁 富士市可愛賽車大賽 (Kawaii Racing)

大耳狗 🆚 布丁狗，在富士山下的雙賽道競速！

- 🐶 開始先選角色（大耳狗／布丁狗）→ 模式（單人對電腦／雙人對戰）→ 車種（Toyota／Mazda／Honda 經典）→ 遊戲開始
- 🗻 沿途是富士山**春夏秋冬**會不斷變換的街景
- 🍓 吃到水果會加分並「變形加速」3 秒
- 🚧 撞到障礙物會變慢 1.5 秒
- 🏁 3 分鐘內比對手先到終點就獲勝，並有超誇張的慶祝畫面
- 🎮 操作 — 1P：← → 轉向、↓ 加速、PgDn 減速；2P：A／D 轉向、S 加速、X 減速（賽車會自動前進，加速為額外加成）

> 註：賽車為**原創的經典車造型**（靈感來自 Toyota／Mazda／Honda），未使用任何官方商標或美術素材。

> 註：遊戲中的角色為**原創的可愛卡通造型（三麗鷗風格）**，以純 SVG 繪製，
> 並未使用任何三麗鷗官方美術素材。架構已預留，日後可替換為正式授權素材。

## 開發 (Development)

```bash
npm install      # 安裝相依套件
npm run dev      # 啟動開發伺服器 (http://localhost:5173)
npm run lint     # 程式碼檢查
npm run build    # 型別檢查 + 產出正式版
npm run preview  # 預覽正式版
```

## 技術 (Tech stack)

Vite + React 18 + TypeScript，純前端單頁應用，無需後端或資料庫。

詳見 `AGENTS.md` 了解專案結構與注意事項。
