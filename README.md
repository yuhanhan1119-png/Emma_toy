# Sanrio 大亂鬥 ✨

可愛的 Sanrio 角色對戰遊戲！

## 角色

- 🍮 **布丁狗** (Pompompurin)
- ☁️ **大耳狗** (Cinnamoroll)
- 🎀 **Hello Kitty**
- 💜 **酷洛米** (Kuromi)
- 🌸 **美樂蒂** (My Melody)

## 遊戲模式

- **單人對戰**：與電腦 AI 對戰
- **雙人對戰**：兩位玩家輪流操作

## 如何遊玩

直接在瀏覽器開啟 `index.html` 即可遊玩，無需安裝。

```bash
# 或使用簡易 HTTP 伺服器
npx serve .
```

### 操作說明

**單人模式**：點擊按鈕選擇 攻擊 / 必殺技 / 治療

**雙人模式**：
- 玩家 1：`A` 攻擊 | `S` 必殺技 | `D` 治療
- 玩家 2：`J` 攻擊 | `K` 必殺技 | `L` 治療

## 遊戲流程

1. 開場動畫 — 五位 Sanrio 夥伴的可愛登場
2. 主選單 — 選擇單人或雙人模式
3. 角色選擇 — 挑選你的戰士
4. 回合制戰鬥 — 攻擊、必殺技、治療，將對手 HP 歸零即獲勝！
